## Lesson 1 — What is Django?

### Technical Definition

**Django is a high-level Python web framework used to build server-side web applications.**

A Django application receives an HTTP request from a client, processes business logic, interacts with a database through its ORM when needed, and returns an HTTP response.

Instead of writing each component from scratch, Django provides them as built-in modules.

---

### Why companies use Django

A typical backend needs:

- URL routing
- Authentication
- Database interaction
- Forms
- Security
- Admin dashboard
- Session management
- Template rendering

Without Django, you implement or integrate many of these yourself.

With Django, these features are already available and designed to work together.

---

### What Django actually does

Suppose a browser requests:

```
GET /students/15
```

Django processes it in this order:

```
Browser
   ↓
URL Dispatcher
   ↓
View
   ↓
Model (if data is required)
   ↓
Database
   ↑
Model
   ↑
View
   ↑
HTTP Response
   ↑
Browser
```

Each part has a specific responsibility:

- **URL Dispatcher:** Chooses which view should handle the request.
- **View:** Contains the application's logic.
- **Model:** Represents and accesses the database.
- **Response:** Sends data back to the client.

We'll study each of these in depth later.

---

### Real-world example

Consider a college portal.

A student opens:

```
/results/20230015
```

Django:

1. Matches the URL.
2. Calls the correct view.
3. Fetches the student's result from the database.
4. Returns an HTML page or JSON response.
