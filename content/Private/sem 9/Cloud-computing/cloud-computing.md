# Cloud Computing

**Course Code:** IC-908A  
**Course Type:** Core  
**Course Credits:** 4  

## Course Objectives
To familiarize students with the core concepts of Cloud Computing Architecture and service models especially focusing on Virtualization, security and Market oriented aspects of cloud computing.

## Course Outcomes
After completion of the course, student will:
- **CO1:** Able to demonstrate basic concepts, principles and paradigm of Cloud Computing and its adoption.
- **CO2:** Able to interpret various Cloud computing models, services and applications.
- **CO3:** Gain insights of significance of implementing virtualization techniques and management of cloud services.
- **CO4:** Illustrate the cloud security vulnerability and the need of security in Cloud computing and Market oriented cloud computing.

## Course Contents

### Unit 1: Introduction to cloud computing
- **Contents:** Historical development, Vision of Cloud Computing, Characteristics of cloud computing as per NIST, Cloud computing reference model, Cloud computing environments, Cloud services requirements.
- **Hours:** 6
- **Targeted Levels of Blooms Taxonomy:** 1, 2
- **Learning Outcomes (LO):**
  - **LO1:** Identify key characteristics of cloud computing according to NIST and cloud computing reference model, environments, and service requirements.
- **Resources:** Book 1, 2 (Lecture), https://www.coursera.org/learn/introduction-to-cloud
- **Assignment:** Assign: questions for key characteristics of cloud computing and discussion.

### Unit 2: Cloud Applications
- **Contents:** Cloud and dynamic infrastructure, Cloud Adoption and rudiments. Overview of cloud applications: ECG Analysis in the cloud, Protein structure prediction, Gene Expression Data Analysis, Satellite Image Processing, CRM and ERP, Social networking.
- **Hours:** 4
- **Targeted Levels of Blooms Taxonomy:** 1, 2
- **Learning Outcomes (LO):**
  - **LO1:** Describe cloud computing, cloud adoption, and various cloud applications.
- **Resources:** Book 1, 2 (Lecture), https://www.redhat.com/en/topics/cloud-native-apps/what-are-cloud-applications
- **Assignment:** Summarize Cloud Applications and discussion.

### Unit 3: Cloud Computing Architecture and Cloud Solutions
- **Contents:** Cloud Reference Model, Types of Clouds, Cloud Interoperability & Standards, Scalability and Fault Tolerance. Cloud Ecosystem, Cloud Business Process Management, Cloud Service Management. Cloud Analytics, Testing Under Control, Virtual Desktop Infrastructure.
- **Hours:** 6
- **Targeted Levels of Blooms Taxonomy:** 1, 2
- **Learning Outcomes (LO):**
  - **LO1:** Recognize and describe key concepts of types of clouds, interoperability, scalability, fault tolerance, BPM, cloud analytics, and other associated solutions.
- **Resources:** Book 1, 2 (Lecture), https://cloud.google.com/learn/what-is-cloud-architecture#section-1
- **Assignment:** Assign: practice and assignment questions on Cloud Reference Model

### Unit 4: Cloud Management
- **Contents:** Resiliency, Provisioning, Asset management, Concepts of Map reduce, Cloud Governance, High Availability and Disaster Recovery.
- **Hours:** 6
- **Targeted Levels of Blooms Taxonomy:** 1
- **Learning Outcomes (LO):**
  - **LO1:** Illustrate concepts of resiliency, provisioning, asset management, MapReduce, cloud governance, high availability, and disaster recovery with the importance and relevance.
- **Resources:** Book 1, 2 (Lecture), https://cloud.google.com/learn/what-is-cloud-management#section-1
- **Assignment:** Assign: practice and assignment questions on Cloud Management

### Unit 5: Virtualization Technology
- **Contents:** Virtualization: Fundamental concepts of types of virtualisation such as: compute, storage, networking, desktop and application virtualization. Virtualisation applications and benefits, server virtualisation, analysis of Block and file level storage virtualisation, evaluation of Hypervisor management software, Infrastructure Requirements, Virtual LAN (VLAN) and Virtual SAN(VSAN) and their benefits.
- **Hours:** 5
- **Targeted Levels of Blooms Taxonomy:** 1, 2, 4
- **Learning Outcomes (LO):**
  - **LO1:** Classify types of virtualization in compute, storage, networking, desktop, and application domains.
  - **LO2:** Explain the benefits of virtualization and understand its practical applications, including server virtualization and storage virtualization.
- **Resources:** Book 1, 2 (Lecture), https://aws.amazon.com/what-is/virtualization/
- **Assignment:** Assignment: compare and contrast different forms of virtualization and discussions

### Unit 6: Cloud Security
- **Contents:** Cloud Information security fundamentals, Identify and analyze cloud computing security challenges Cloud security services, Design principles, Secure Cloud Software Requirements, Cloud Computing Security Challenges, Virtualization security Management, Cloud Computing Security Architecture.
- **Hours:** 7
- **Targeted Levels of Blooms Taxonomy:** 1, 2, 3, 4.
- **Learning Outcomes (LO):**
  - **LO1:** Identify and Comprehend cloud information security fundamentals, design principles, security services, requirements, challenges, virtualization security management, and cloud computing security architecture.
- **Resources:** Book 1, 2 (Lecture), https://www.ibm.com/topics/cloud-security
- **Assignment:** Questions on security services, requirements, challenges, virtualization security

### Unit 7: Market Oriented Cloud computing
- **Contents:** Market Based Management of Clouds, Federated Clouds/Inter Cloud: Characterization & Definition, Cloud Federation Stack, Third Party Cloud Services. Case study: Google App Engine, Microsoft Azure.
- **Hours:** 8
- **Targeted Levels of Blooms Taxonomy:** 1, 2, 4
- **Learning Outcomes (LO):**
  - **LO1:** Identify the role and benefits of third-party cloud services in cloud computing with Analysis of case studies of Google App Engine and Microsoft Azure in cloud computing.
- **Resources:** Book 1, 2 (Lecture), https://arxiv.org/ftp/arxiv/papers/0808/0808.3558.pdf
- **Assignment:** Questions on Market Based Management of Clouds and third-party services
