# Cloud Computing Syllabus Tracker

This file tracks the topics covered in the Cloud Computing PG syllabus.

## Completed Topics

1. **Historical Development of Cloud Computing**
   - **Learned:** The evolutionary stages of computing paradigms: Mainframe (centralized) -> Personal Computing (decentralized) -> Client-Server -> Grid Computing -> Utility Computing -> Cloud Computing (virtualization + utility model).
2. **Vision of Cloud Computing**
   - **Learned:** The transformation of IT into a utility service based on three pillars: The Utility Model (pay-as-you-go), Illusion of Infinite Capacity (elasticity), and Abstraction of Complexity (hardware management by provider).
3. **Characteristics of Cloud Computing as per NIST**
   - **Learned:** The 5 essential characteristics defining a cloud: On-demand Self-service, Broad Network Access, Resource Pooling, Rapid Elasticity, and Measured Service.
