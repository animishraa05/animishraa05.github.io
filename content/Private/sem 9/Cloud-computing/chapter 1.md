
#### cloud computing Vision
-  Cloud Computing ka main "vision" (maqsad) ye hai ki IT ko ek mehnga hardware kharidne wale model se hatakar
  ek aisi service banaya jaye jo jab chaho tab mil jaye. Iske 3 main points hain:

  1. The Utility Model (The 5th Utility): Jaise hum bijli ya paani ka use karte hain—switch on kiya aur jitna use kiya utna bill aaya. Cloud ka vision yahi hai ki computing power (servers, storage) bhi exactly waise hi available ho. Aapko hardware kharidne ki zarurat nahi, bas internet se connect karo aur 'Pay-as-you-go'model par use karo.
  2. Illusion of Infinite Capacity: Ek developer ya company ko hamesha yahi lagna chahiye ki cloud ke paas unlimited space aur power hai. Agar aapki app par achanak se bohot saare users aa jayein, toh cloud us load ko apne aap handle kar le bina crash hue. User ko kabhi hardware limitations ki tension na leni pade. 
  3. Abstraction of Complexity: Jo piche data center mein physical servers, wires, AC cooling, aur hardware management chal raha hai, uski headache user ki nahi honi chahiye. User sirf apni application par focus kare, aur baaki saari hardware ki complexity cloud provider (jaise AWS, Azure) khud sambhale.


#### Cloud computing characterstics
There are mainly 5 characterstics of cloud computing.
- On demand self service
- metered connection
- broad area network
- Rapid elasticity 
- resource pooling
These are according to *nist*, national institute of standards and technology
